# Risorse Esterne Utili — Gilda Bloods

> Lista centralizzata dei tool e siti utili per chi gioca in WoW.
> Non è esaustiva, copre il 90% di quello che serve a un raider/M+/PvP della gilda.
- Se manca qualcosa di utile, segnalalo in `#faq` su Discord.

---

## Addon Manager

| Tool | Link | Note |
|------|------|------|
| CurseForge | https://www.curseforge.com | Addon manager standard. Installa, aggiorna, gestisci tutti gli addon da qui. |

> Alternativa: Wago Addon Manager (https://addons.wago.io) — più leggero, niente ads, supporta WA. Scelta personale.

---

## Guide di Classe

| Sito | Link | Per cosa |
|------|------|----------|
| Icy Veins | https://www.icy-veins.com/wow | Guide classe/spec, rotation, talent, gear, beginner-friendly. |
| Wowhead Guides | https://www.wowhead.com/guides | Guide classe + class analysis, tier set, trinket, macro. |
| Maxroll WoW | https://maxroll.gg/wow | Guide compatte, build, tier list. Buone per quick reference. |

> Per la spec precisa: confronta almeno due fonti. I tier set e i trinket cambiano i build, non copiare a occhi chiusi.

## Guide Boss / Raid

| Sito/Canale | Link | Per cosa |
|-------------|------|----------|
| Wowhead Raid Guides | https://www.wowhead.com/raids | Guide scritte per ogni boss, meccaniche, loot. |
| Method | https://method.gg | Strutture tattiche, log, world first tracking. |
| FatbossTV (YouTube) | cerca "FatbossTV [nome raid]" | Video guide dettagliate, ~15-20 min per boss. |
| Ready Check Pull (YouTube) | cerca "Ready Check Pull [nome boss]" | Video guide rapide, 5-10 min. Ideali pre-pull. |

## Checklist tool minima (Raider)

- [ ] CurseForge installato (addon aggiornati).
- [ ] DBM o BigWigs installato e aggiornato.
- [ ] WeakAuras installato + WA string dei boss.
- [ ] Details! installato.
- [ ] Account Warcraft Logs + Advanced Combat Logging ON.
- [ ] Raider.io profile collegato.
- [ ] Raidbots account (anche free) per simulazioni.
- [ ] SimulationCraft addon per export profilo.
- [ ] Discord Bloods joined + notifiche `#tattiche` e `#prenotazione-incursioni` attive.
