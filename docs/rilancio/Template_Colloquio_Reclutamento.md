# Template Colloquio di Reclutamento — Gilda Bloods

> Da usare in ticket Discord durante il colloquio. Tempo target: ~10 minuti.
> Compila le risposte nel ticket per archiviale. Alla fine, assegna al player il tag più adatto (`@Raider`, `@Raider Mitico`, `@PvP`, `@Social`).

---

## Domande del colloquio

1. **Nome battaglia (BattleTag) e main PG** — nome del personaggio + realm.
2. **Da quanto tempo giochi a World of Warcraft?** E a questa espansione (Midnight) specificamente?
3. **Hai fatto parte di altre gilde in passato? Quali?**
4. **Nella tua vecchia gilda che ruolo occupavi?** (membro, raider, officer, RL, ecc.)
5. **Come mai hai lasciato la vecchia gilda?**
6. **Ruolo attuale** (Tank / Healer / DPS) e **classi main + alt**.
7. **Quanti personaggi hai sull'account?** Altri personaggi in altre gilde?
8. **Progress attuale:**
   - Raid: che tier, che difficoltà, che boss
   - M+: rating M+ season
   - PvP: rating arena 2v2/3v3, rating RBG
9. **Esperienza mitica pregressa?** (tier passati, anche altre espansioni)
10. **Disponibilità settimanale** — giorni e fasce orarie in cui sei online.
11. **Obiettivi nella gilda** — raid mitico / M+ push / PvP / social / imparare.
12. **Discord + microfono funzionanti?** (sì/no, se no perché)
13. **Come ci hai trovati?** (LFG, Discord community, Reddit, Facebook, amico, ecc.)
14. **Altro che vuoi dirci?** (libero)

---

## Criteri di assegnazione tag

### → @Raider / @Raider Mitico (roster progress)
- Esperienza raid almeno Heroic, preferibilmente qualche kill mitica pregressa.
- M+ rating ≥ +6/+8 settimanale o superiore.
- Disponibilità ≥ 2 sere/sett per raid + 1 per M+.
- Gear in linea col tier (valutato a inizio season).
- Obiettivo dichiarato: progress mitico.
- Se soddisfa tutti i requisiti Raider Mitico (vedi file dedicato) e c'è slot → `@Raider Mitico`.
- Altrimenti → `@Raider` con percorso chiaro per salire.

### → @Social (social / returning / casual)
- Nuovo player, returning player, o player casual.
- Nessuna o poca esperienza raid.
- Vuole giocare in gruppo senza gli obblighi del roster mitico.
- Disponibilità variabile.
- Obiettivo dichiarato: imparare / social / M+ casuale / eventi.
- Può salire a `@Raider` seguendo il percorso di progressione con mentorship.

### → @PvP (tag aggiuntivo)
- Player PvP puro o player raid che vuole anche spingere PvP.
- Rating ≥ 1600 (arena o RBG) o voglia dichiarata di crescere PvP.
- Disponibilità Mer sera + weekend.
- Si combina con altri tag (es. `@Raider` + `@PvP`, o `@Social` + `@PvP`).

## Workflow post-colloquio

1. **Officer assegna:**
   - Gilda in-game (BLOODS) — gilda sempre il MAIN PG.
   - Ruolo Discord: `Membro` + tag ruolo (`Tank`/`DPS`/`Healer`) + tag attività (`Raider`/`Raider Mitico`/`PvP`/`Social`).
   - Nickname normalizzato: `NOME MAIN PG - NOME ANAGRAFICO - RUOLO`.
2. **Note riservate Officer:** data ingresso + esito colloquio + assegnazione tag.
3. **Invito al canale `#presentazioni`** — il nuovo membro si presenta (template fornito).
4. **Mentor assegnato** (per @Social che vuole salire a Raider, o per @Raider che punta al Mitico).
5. **Onboarding bot Bloods Points** — spiegazione comando `/bp` e regole loot.
