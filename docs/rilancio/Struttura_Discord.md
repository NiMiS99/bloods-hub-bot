## Onboarding (flow reale)

### Fase 1: Verifica anti-bot (automatica)
1. Utente entra → bot assegna `@Non Verificato`
2. Vede solo `Area Iniziale` (Benvenuto, Regolamento, Invito, Comandi-Bot, Scegli-Giochi)
3. Clicca bottone **"Verifica"** in `#Benvenuto`
4. Bot invia **CAPTCHA**
5. CAPTCHA superato → bot assegna `@Membro della community`
6. Bot invia **DM di benvenuto** con lista comandi
7. Bot post messaggio di benvenuto in chat pubblica
8. Utente seleziona giochi in `#scegli-giochi`

### Fase 2: Colloquio gilda WoW (manuale)
1. Utente apre ticket in `#ticket-assistenza`
2. Officer fa colloquio (template: `Template_Colloquio_Reclutamento.md`)
3. Esito positivo → Officer assegna `@Bloods` + tag WoW
4. Nickname: `NOME MAIN PG - NOME ANAGRAFICO - RUOLO`
5. Link PG: `/link battlenet NomePG-Reame`
6. Presentazione in `#Presentazioni`

### Fase 3: Setup raid (per Raider)
1. Addon: `Guida_Addon_Configurazione.md`
2. WeakAuras: `WeakAura_Collection_Bloods.md`
3. Tattiche: `#Tattiche` + `Guide_Tattiche_Venomous_Abyss.md`
4. Pre-iscrizione: `/spedizione` o `#Prenotazione-Incurzioni`
5. Check idoneità: `/raidstatus me`
6. Saldo BP: `/bp balance`
