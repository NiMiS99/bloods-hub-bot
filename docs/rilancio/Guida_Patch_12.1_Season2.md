## Gear e progression Season 2

### Item level reference
| Source | ilvl | Note |
|--------|------|------|
| Mythic 0 | 292 | Daily reset in S2 |
| Heroic dungeon | ~276 | Base gear |
| Normal raid | 302-305 | First 4 bosses / last 4 |
| Heroic raid | 308-311 | |
| Mythic raid | 319-344 | Last 2 bosses drop 344 |
| M+ +10 | ~311 | Crest tier dipende dal key level |
| PvP | scale con rating | |

### Come gearizzarsi in S2
1. **Primi giorni:** world content su The Coiled Isle, world quest, rares, world boss
2. **Settimana 1:** Mythic 0 dungeon (292 ilvl), Heroic dungeon
3. **Settimana 1-2:** Normal raid (Venomous Abyss) — clear 8/8 N
4. **Settimana 2+:** Heroic raid progress + M+ push (+6/+8/+10)
5. **Settimana 4+:** Mythic raid progress + M+ +10/+12

### Crests e upgrade
- I boss del raid droppano **Mistcrests** (tier dipende dalla difficoltà)
- I M+ droppano crest in base al key level
- Usa i crest per upgrade gear al NPC di upgrade
- **Catalyst:** converte gear non-tier in tier set (slot specifici, refresh settimanale)
